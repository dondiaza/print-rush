# Objetos

El registro compartido define Thread Boost, T-Shirt Cannon, Sticker Mine y Package Shield con categoría, duración, cooldown y pesos por posición. El RNG usa una semilla reproducible.

El vertical slice activa Thread Boost de extremo a extremo: pickup visible, inventario HUD, consumo y boost limitado. Los otros registros preparan la siguiente expansión; no aparecen como botones ni efectos falsos.
